# Claude Code Onboarding Guide — 5-Minute Read

## What Claude Code Is

Claude Code is an AI assistant that works directly inside your project folder — it can read your files, write new ones, run searches, and remember context by writing it down, not by "remembering" like a chat app does. Think of it less like a chatbot and more like a very fast, very literal collaborator who only knows what's actually written in your files.

## What You'll Build in Your First Session

You'll use one prompt (below) to have Claude interview you about your product, your role, your team, and how you want things organized — then it sets up a working PM workspace from scratch: a `CLAUDE.md` file (your project's memory), a folder structure, and the hard rules that keep everything it writes accurate and properly sourced. By the end of a 15-minute demo, you'll run this exact process yourself, for your own product, in a brand-new folder.

## The 3 Habits That Matter Most

1. **Update CLAUDE.md every session.** This file is the only thing Claude reliably "remembers" between sessions — it doesn't have memory the way a person does. If something important changed (a decision, a new person, a status update) and CLAUDE.md doesn't reflect it, the next session starts out of date.
2. **Use the AI interview before building anything.** Don't jump straight to "write me a PRD" or "build me a prototype." Let Claude ask you questions first — one at a time — until it actually understands what you need. Output built without that context tends to be generic; output built after a real interview is grounded in your specifics.
3. **Save everything.** Claude will proactively offer to save useful conversation content to a file — say yes. A great answer that only exists in the chat window is gone once the session ends. A saved file is something next week's you (or a teammate) can actually use.

## The Single Most Common Mistake

**Assuming Claude remembers your last conversation.** It doesn't — there's no persistent memory beyond what's written down in your files. If you had a great planning conversation last week but never saved it anywhere, today's session starts from zero on that topic. The fix is simple but easy to forget: treat "did I save this?" as the real question, not "did Claude understand this?" — understanding without a saved file evaporates the moment the session ends.
